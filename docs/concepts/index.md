# Concepts
This section provides a reference for the concepts and features of Sonolus.py. Background knowledge of Python
fundamentals is assumed.

- [Overview](overview.md): A summary of the whole library.
- [Types](types.md): `Num`, `Array`, `Record`, generics, and copy versus alias semantics.
- [Constructs](constructs.md): The supported Python subset and how it differs from standard Python.
- [Builtins](builtins.md): Supported built-in functions and standard library modules.
- [Project](project.md): Project layout, modes, archetype callbacks, and levels.
- [Resources & Declarations](resources.md): Entity and level storage, skins, effects, particles, buckets, and options.
- [Command Line](cli.md): The `sonolus-py` tool for building, serving, and checking a project.
